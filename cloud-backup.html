Gloria private cloud backup

This optional tool encrypts a verified copy of the progress stored in this browser before uploading. It never changes your saved progress. If you are using another device, open this page on the device holding the progress.

Important: No upload can happen without the private upload token and a separate passphrase (at least 16 characters). Manual upload keeps them only on this page. Choosing automatic backups stores the upload token and encryption passphrase in this browser's private IndexedDB storage (accessible to scripts on the same website); use only on your trusted iPad. Keep the passphrase separately for recovery. The token is not your Cloudflare API token.
