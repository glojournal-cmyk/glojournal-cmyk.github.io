Overview

This lesson contains 50 enabled questions. It teaches Quick rules through explicit translation, recall, grammar and application tasks.

Watch for

Using du after aimer + noun. Keeping du/de la after a negative. Using avoir with aller. Forgetting agreement with elles.

J’aime le riz. / Je préfère regarder la télé.

APPLY THE RULE

With a noun after aimer / adorer / détester / préférer, use the definite article (le / la / l’ / les). With another verb, use the infinitive without an article.

Must remember

  • ✓Recall the core language for Quick rules.
  • ✓Identify the task direction before writing.
  • ✓Explain errors by naming the article, subject, tense, auxiliary, agreement or negative rule.
  • ✓Use the material in a short controlled sentence.
  • ✓Opinion + noun takes le/la/l’/les.
  • ✓Food and drink quantities take du/de la/de l’/des.
  • ✓After ne…pas or ne…plus before a noun, use de/d’.
  • ✓After aller, choose au/à la/à l’/aux from the place noun.
  • ✓Passé composé = auxiliary + past participle.
  • ✓Movement/reflexive verbs using être may require agreement.

Watch for

  • Using du after aimer + noun.
  • Keeping du/de la after a negative.
  • Using avoir with aller.
  • Forgetting agreement with elles.
