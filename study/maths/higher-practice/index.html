Let x=2a, y=2b, where a,b are positive integers. Given xy=27 and x2/y=22, double x and halve y. Evaluate (x2y-1)2x-1y using the NEW values of x and y.

Worked solution

  1. a+b=7 and 2a−b=2 imply a=3,b=4.
  2. New x=2^4, new y=2^3. The expression simplifies to x^5/y^3.
  3. Value=2^(20−9)=2048.

For positive x,y define E=(x2y-1)2/(x-2y4). Experiment A doubles x and halves y. Experiment B multiplies the original x by 2a and the original y by 4, where a is an integer. The value of E in A is 64 times its value in B. Find the factor by which x is multiplied in B.

Worked solution

  1. E=x^6/y^6. Experiment A gives multiplier 2^12.
  2. Experiment B gives multiplier 2^(6a−12). Their ratio is 2^(24−6a)=2^6.
  3. a=3, so factor=8.

Fixed integers n and k satisfy (x3y2)nx2y5=x10yk whenever y=x2 and whenever y=1/x, for every positive x. Which ordered pair (n,k) satisfies both conditions?

Worked solution

  1. The left side is x^{3n−2}y^{2n−5}. Substituting y=x² gives 7n−12=10+2k, or 7n−2k=22.
  2. Substituting y=1/x gives n+3=10−k, so n+k=7.
  3. Eliminate k: 9n=36, so n=4,k=3. The original exponents then match for every positive x,y.

For integers n>m, define A=5·2n+2m and B=5·2m+2n. Given A/B=41/13 and A=1312, find 2n+m.

Worked solution

  1. Let t=2^(n−m). Then (5t+1)/(5+t)=41/13, giving 65t+13=205+41t, so t=8.
  2. A=(5t+1)2^m=41·2^m=1312, so 2^m=32 and m5; n8.
  3. 2^(n+m)=2^13=8192.

Positive x,y are scaled by factors 2a and 2b, where a,b are nonzero integers with |a|≤6 and |b|≤6. The value of x6/y4 stays unchanged. The value of x2y must increase. Find the greatest possible factor by which x2y increases.

For integer n, define G(n)=16n2+18n-2. Given G(n-3)=32G(n+2), find G(n).

Worked solution

  1. G(n)=2^{2n²−3n+8}. Subtract the exponent at n+2 from the exponent at n−3 to get 25−20n.
  2. The ratio is 2^5, so 25−20n=5 and n=1.
  3. G(1)=2^{2−3+8}=2^7=128.

A tank contains 2×105 mL of solution at concentration 3×10-4 g/mL. One quarter of this well-mixed solution is removed. Pure water is then added in complete 2.5×104 mL batches. The final concentration must be between 8×10-5 and 9×10-5 g/mL inclusive. Assuming additive volumes and no further salt loss, find the greatest volume of water that can be added, in mL. Give your answer in standard form.

Worked solution

  1. Removing one quarter leaves 150000 mL and 45 g of salt.
  2. The concentration bounds imply 500000≤total volume≤562500, or 350000≤added volume≤412500.
  3. The largest multiple of 25000 in this interval is 400000 (16 batches), giving concentration 45/550000≈8.18×10^-5 g/mL.

Two detectors run one after the other for a total of 3.0×102 seconds. Detector A records 3.2×105 pulses per second and B records 4.8×104 pulses per second. In a second trial they run for exactly the same respective times. A's rate increases by 4.0×104 pulses per second and B's rate decreases by 2.0×104 pulses per second. The combined number of pulses stays the same. How many pulses were recorded in the first trial? Give your answer in standard form.

Worked solution

  1. Let A run for a seconds and B for b seconds. The unchanged total means the additional 40,000a pulses equal the lost 20,000b pulses.
  2. Thus b=2a. The two times sum to 300 s, so a=100 and b=200.
  3. The first trial records 32,000,000 + 9,600,000 = 41,600,000 pulses.

Instrument A reads 6×108 milliunits and instrument B reads 4×105 units, where 1000 milliunits = 1 unit. In each complete calibration step, A's reading decreases by 2.5×104 units and B's reading increases by 1.5×104 units. Both instruments undergo the same non-negative whole number of steps. Their combined corrected reading must be between 9.5×105 and 9.7×105 units inclusive, and A must read at least 4×104 units more than B. Find the greatest possible total reduction in A's reading, in units and in standard form.

Worked solution

  1. A initially reads 6×10^5 units and B reads 4×10^5 units. After n steps their sum is 10^6−10^4n and their difference is 2×10^5−4×10^4n.
  2. The combined reading permits n=3,4,5. The differences are 80000,40000,0 respectively; the last fails the minimum difference.
  3. Four is the greatest valid step count. A decreases by 4×2.5×10^4=1×10^5 units.

Pump A delivers 2.4×10-3 m³ per minute and pump B delivers 6×10-4 m³ per minute. Each of two separate runs starts with an empty tank. In both runs A operates for all 150 minutes and B starts once, then runs until the end. In run 1, water leaks out at an unknown constant rate L m³ per minute, and the final volume is 3.6×10-1 m³. In run 2, B starts 30 minutes earlier than in run 1, but the leak rate is twice L. The final volume in run 2 is 3.42×10-1 m³. Which pair gives (L in m³ per minute, the time in seconds before B starts in run 1), both in standard form?

Worked solution

  1. Let B run for t minutes in run 1. The first-run balance is 0.36+0.0006t−150L=0.36.
  2. Run 2 has B duration t+30 and leakage 300L. Subtract run 1 balance: 0.0006×30−150L=0.342−0.36=−0.018.
  3. Hence 150L=0.036, L=0.00024=2.4×10^−4. First balance gives 0.0006t=0.036, t=60 minutes.
  4. B starts after 150−60=90 minutes=5400 seconds=5.4×10^3. Check run 2: 0.36+0.054−0.072=0.342.

A data link has capacity 7.5×108 bytes per session, including a fixed overhead of 1.5×108 bytes. A large file uses 2.4×105 bytes and a small file uses 1.2×105 bytes. Exactly 3×103 complete files must be sent, with at least one quarter large. Find the greatest number of large files that can be sent. Give your answer in standard form.

Worked solution

  1. All 3000 files treated as small would use 3.6×10^8 bytes. The available capacity after overhead is 6×10^8.
  2. Each large file adds 1.2×10^5 bytes. Thus the number L of large files obeys 1.2×10^5 L≤2.4×10^8, or L≤2000.
  3. The minimum is 750. Taking L=2000 and 1000 small files exactly meets capacity and all constraints.

The original system is 3x+2y=17 and 5x-2y=7. In experiment 1, add p to the first right-hand side and q to the second. The resulting solution has the same value of x+y as the original solution. In experiment 2, start again from the original system but add q to the first right-hand side and p to the second. The resulting value of x−y is 2 less than the original value of x−y. Find the ordered pair (p,q).

Worked solution

  1. Original solution is (3,4), with sum7 and difference−1. In experiment 1, x+y=7, hence y=7−x.
  2. Then 3x+2(7−x)=17+p gives x=3+p. The second equation yields 5x−2(7−x)=7+q, so q=7p.
  3. In experiment 2, x−y=−3, hence y=x+3. First equation gives 5x+6=17+q, or 5x=11+q. Second gives 3x−6=7+p, or 3x=13+p.
  4. Eliminate x: 3(11+q)=5(13+p), so 3q−5p=32. Substitute q=7p: 16p=32, p=2 and q=14.
  5. Check experiment 1: RHS19,21 gives (5,2), sum7. Experiment 2: RHS31,9 gives (5,8), difference−3.

A package contains exactly 12 components, each a block or rod, and weighs 12 kg before packaging. Wrapping adds 150 g. As many rods as possible are then exchanged for blocks without the wrapped package exceeding 16 kg. Find the final mass in grams.

Worked solution

  1. Solve the two mass equations: a block weighs 1.8 kg, a rod 0.6 kg. For 12 components of total 12 kg, 1.8b+0.6(12−b)=12 gives four blocks and eight rods.
  2. Each exchange increases mass by 1.2 kg. With wrapping, 12.15+1.2e≤16 gives e≤3.208..., so at most three whole exchanges; eight rods are available.
