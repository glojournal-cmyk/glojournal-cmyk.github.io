Import Scholar progress

Use a standard Scholar Garden JSON exported from Scholar → Export progress. No password or passphrase is needed.

This is a standalone import page on the same Gloria website. Loading or previewing a file does not change any progress.

Have the JSON in Files or Downloads. For a passphrase-protected Cloud Backup, use the encrypted restore tool instead.

Compare before importing

This import preserves existing date-stamped completion proof where possible. It cannot recover records absent from the selected JSON.

Protect the existing device

Before changing any local progress, download a separate safety copy of the progress already stored on this device. Check the file exists in Files or Downloads.

Cancel without importing

Do not clear Safari website data, uninstall the iPad app or delete your original JSON. If device storage is full, import will stop without deleting the existing record.
