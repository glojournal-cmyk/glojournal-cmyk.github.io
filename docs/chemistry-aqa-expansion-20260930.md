## AQA alignment

- [8462, section 4.1.1.2: mixtures and separation; section 4.1.2.2: periodic-table development](https://www.aqa.org.uk/subjects/chemistry/gcse/chemistry-8462/specification/subject-content/atomic-structure-and-the-periodic-table)
- [8462, section 4.8.1.3: chromatography and Rf](https://www.aqa.org.uk/subjects/chemistry/gcse/chemistry-8462/specification/subject-content/chemical-analysis)
- [8462 practical assessment: apparatus, measurement, safety and separation](https://www.aqa.org.uk/subjects/chemistry/gcse/chemistry-8462/specification/practical-assessment)

The style uses short describe, explain, compare, evaluate and calculate prompts, with 2–4 distinct mark points. Matching Rf supports a possible identity under the same conditions. A single spot in one solvent is treated as limited evidence of purity. Solubility facts for unfamiliar solids are supplied in the question.

## App behaviour

The assessment bank now contains 190 base questions plus 28 existing school-style questions (218 total). The same 60 new questions are available in the relevant C1, C3 and C4 Master banks. Topic and catalogue counts are updated.

Each new short-answer point is worth one mark. The calculation rubric separates method from final value and required unit. The 30-question, 45-minute paper blends the new multi-mark questions with older one-mark questions to retain manageable length. The existing topic quotas, including nine Rf questions, remain. Each concept and diagram can occur at most once per paper. Drafts already answered remain intact.

Automated marking is based on declared alternative phrases and numerical patterns. Worked model answers and hints are shown only after submission. The same answer records also contain the standard Master-bank fields so the post-exam Practise import remains usable.
