# Wardrobe update

Adds 8 full-look wardrobe choices:
- Pinafore
- School Blazer
- Winter Coat
- Denim Jacket
- Track Jacket
- Summer Look
- Hoodie
- French Beret

Files:
- src/lib/content/outfits.ts
- src/components/wardrobe-game.tsx
- public/art/wardrobe/*.png
- public/art/closet/*.jpg

The PNG full looks use the cleaned transparent doll assets already present in art.zip.
The closet images are square wardrobe thumbnails generated from those cleaned assets.

Install:
Copy the contents of this ZIP into the root of giant-blend-cobalt-thunder,
allowing matching folders to merge/overwrite. Then commit and push with GitHub Desktop.
