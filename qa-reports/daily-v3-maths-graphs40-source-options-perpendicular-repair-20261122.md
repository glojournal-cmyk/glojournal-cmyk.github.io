These four are now explicitly flagged for **exact taught perpendicular-gradient evidence** in the new QA register. Perpendicular gradient by itself is **not automatically asserted** to be Spring-only; actual teacher syllabus proof is needed. Overall **32/40** source questions need some form of perpendicular-taught proof following this correction.
3. **Top provisional grade result repetition:** source **Q157–160** are marked provisional G8–9, but all four calculate **xP+yP=7**, despite changed coordinates/lines. They are not four independent high-band concepts merely because four worded variants exist; correction is necessary before academic import.
4. **Uncertain grade bands:** original source selection triage is **20 scope quarantine, 4 upgrade stem, 16 candidates for independent external benchmark**. None of the 16 is signed Grade 7–9, and none of the 40 has a teacher approved set of five credible mathematical misconceptions.
5. **Actual PDF visual mathematical fidelity:** e.g. Q121 and Q141 have vertically stacked answers. Text extraction can attach a numerator to the previous choice, so the exact visually printed A–F option formulas cannot be self-certified from the source extract.
